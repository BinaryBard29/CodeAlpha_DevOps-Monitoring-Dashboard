# DevOps Monitoring Dashboard

A modern real-time DevOps Monitoring Dashboard built using Java, Gradle, JavaFX, and OSHI.

This project provides live system monitoring with a futuristic DevOps-style UI including:

* Live CPU monitoring
* RAM usage tracking
* Disk usage analytics
* Real-time network monitoring
* Upload and download speed tracking
* Ping latency monitoring
* Live performance graphs
* Neon glassmorphism UI
* Animated dashboard cards
